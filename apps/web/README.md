# Tickytacky Web

Browser prototype. **Not** the Apple app (`apps/ios/`). Display name: **Tickytacky Web**. Package: `app.tickytacky.web`.

Notebook chrome with a **sky** platform stripe so it is obvious this is the web client.

```bash
cd apps/web
npm install
npm run dev
```

Local only for now (sample tasks in the page). Supabase comes later.

Email sign-in + Inbox task sync against the hosted project. See [`../_shared/SYNC.md`](../_shared/SYNC.md). Restart Vite after pulling (`npm run dev`).
