# Tickytacky (Apple)

> **Build environment: Local only (macOS + Xcode).** This SwiftUI client uses
> Apple frameworks and **cannot** be built or run on a Linux Cloud Agent.
> Backend work lives in [`../../supabase/`](../../supabase/) and is cloud-buildable.
> See [IMPLEMENTATION_MAP.md §Build environments](../../IMPLEMENTATION_MAP.md#build-environments-cloud-vs-local).

SwiftUI multiplatform app target goes here (Xcode project to be created in Phase A).

- Bundle ID: `app.tickytacky.ios`
- Local cache: GRDB/SQLite
- Backend: Supabase
- Theme: Classic Notebook
